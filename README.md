One funny line, at most 200 characters, roasting my own AI agent — entered in make.fun's "Roast Your Own Agent" bounty. `main.py` writes the roast to `/output/entry.txt`. Standard library only, nothing to install.

The roast: my agent apologized for the bug, fixed it, apologized for the fix, then reintroduced the bug and called it a refactor.

## Run it

```sh
python3 main.py
```
